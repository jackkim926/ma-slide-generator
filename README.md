# M&A 인수 사례 장표 생성기

M&A 기사 3~5건을 입력하면 **1장짜리 인수 사례 분석 장표(PPTX)** 를 만들어 주는 단일 HTML 도구.

`ma-slide-generator.html` 파일 하나를 브라우저로 열면 끝입니다. 설치·빌드·서버가 필요 없습니다.

## 설계 원칙

**API 연동 없음.** 외부 API·계정·키를 일절 쓰지 않습니다. 네트워크 요청(`fetch`)이 한 줄도 없고, 밖으로 나가는 동작은 사용자가 직접 누르는 Google 검색 버튼(새 탭 열기)뿐입니다. 입력값은 브라우저 `localStorage` 에만 저장됩니다.

**라이브러리 없음.** PptxGenJS·JSZip 같은 의존성 없이 ZIP writer(CRC32 + store 방식)와 OOXML 문자열 생성기를 직접 구현해 `.pptx` 를 조립합니다. 그래서 파일 하나로 완결되고 오프라인에서 동작합니다.

**미리보기 = 출력물.** 화면 미리보기와 PPTX가 같은 좌표 계산 함수(`layout()`)를 공유합니다. 화면에서 보이는 배치가 곧 PowerPoint에서 열리는 배치입니다.

## 쓰는 법

1. **기사 링크 3~5개** 를 한 줄에 하나씩 붙여넣고 `링크 읽어들이기`
   → 매체명과 게재일을 도메인·URL 경로에서 자동 추정합니다 (Ad Age, Campaign, The Drum, Mumbrella, 매일경제, 더벨 등 40여 개 매핑, `/2026/08/20/` → `'26.08.20`)
2. **기본 정보 · 헤드라인** 입력, 액센트 컬러 선택
3. **4분면 내용** 입력 — 한 줄에 `라벨 | 값` 형식
   - 좌상 Overview (피인수사 개요)
   - 우상 Strategic Rationale (인수 배경·전략)
   - 좌하 Deal Snapshot (딜 개요)
   - 우하 Implication (시사점, 불릿)
4. `PPTX 다운로드`

처음이면 `8. 출력 → 예시 채우기` 로 완성된 샘플을 먼저 보세요.

> **예시 데이터 주의** — `예시 채우기` 가 넣는 텍스트는 레이아웃 분량을 보여주기 위한 **플레이스홀더**입니다. 실제로 검증된 분석이 아니고 각주 번호도 형식만 갖춘 것이니, 실무에 쓸 때는 기사에서 확인한 내용으로 전부 교체하세요.

### 각주

본문 아무 데나 `[1]` `[2,3]` 을 쓰면 기사 번호가 **위첨자 각주**로 붙고, 하단 출처 줄에는 실제 하이퍼링크가 걸립니다.

### 레이아웃 자동 조정

4분면의 세로 위치를 내용 길이에 따라 계산합니다. 분량이 넘치면 본문을 12pt → 11pt → 10pt 로 자동 축소하고, 그래도 넘치면 **몇 인치 넘쳤는지 경고**합니다. 조용히 깨진 장표가 나가는 걸 막기 위해서입니다.

## 스타일 기준

기준이 되는 M&A 동향 덱을 전수 스캔해 얻은 실측값을 그대로 씁니다.

- 캔버스 13.333 × 7.5 in (16:9)
- 폰트 **Freesentation**(프리젠테이션 3/5/6/7/8), 전 텍스트 자간 **−0.7pt**
- 표 — 라벨셀 `#000000` + 흰 글씨 가운데정렬, 값셀 `#F2F2F2`, **테두리 없음**, 12pt SemiBold
- 섹션 라벨 `▶ Title` — `▶` 만 액센트 컬러, 14pt ExtraBold
- 상단 액센트바 + 우측 페이지 도트 8개

액센트 컬러 프리셋 — 광고 지주사별로 장표 톤을 구분할 때 씁니다. 직접 입력도 가능합니다.

| 그룹 | 액센트 | 박스 틴트 |
|---|---|---|
| Omnicom | `E27041` | `E7E6E6` |
| Accenture Song | `9728F5` | `E8CFFD` |
| Publicis | `85743A` | `E7DFC7` |
| Hakuhodo | `3333FF` | `E7E6E6` |

> 폰트는 Freesentation 이 설치된 PC에서만 원본과 동일하게 렌더됩니다. 미설치 시 Pretendard 로 대체하거나, 도구에서 출력 폰트를 `Pretendard` 로 바꾸세요.
